# Working on Scratch

- Follow the product scope and milestone order in [SPEC.md](SPEC.md). Ask before changing the six default lists or the one-level subtask limit.
- Work in small vertical slices and commit after each working slice with a clear message.
- Never commit, push, pull, or perform similar operations on `main` unless the user explicitly authorizes it.
- Keep views small and keep UI code out of the data layer.
- Unit-test data-layer add, toggle, reorder, nest, and clear-completed operations.
- Run the app and check focus and unfocus behavior after any window change.
- Never use force unwraps or force-try in production code.
