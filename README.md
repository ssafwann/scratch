# Scratch

Scratch is an open-source macOS sticky-note to-do app in development. When the note loses focus, it shows the list name and tasks. When it gains focus, it reveals the controls for editing and organizing the list.

Scratch targets macOS 14 and later on Apple silicon and Intel. See the [product specification](SPEC.md) for the intended behavior and development milestones.

## Run from source

Open `Scratch.xcodeproj` in Xcode, select the Scratch scheme, and press Cmd+R. The current panel spike uses sample tasks to exercise focus, pinning, and window restoration.
